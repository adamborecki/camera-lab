# Reference photos

Real recitals and booths, for whoever draws or tunes the simulator's scenes
(`js/scenes/salmon.js`, `js/scenes/hall-kit.js`). **Not used by the app and not
published on the site** — `tools/build-pages.sh` strips this folder from the
Pages build. They are still public in this repository.

- `salmon/` — Salmon Recital Hall from the booth (the RovoCam static wide on
  Vimeo, and one phone photo from the booth): the instrumentations the scene's
  programs are modeled on.
- `musco/` — Musco Center booth: the ATEM multiview, the switcher desk, the room.

Privacy: performer names in Vimeo titles were cropped out and a sticky note was
blurred before committing. Performers' and crew faces are visible; the
instructor approved committing these for reference (Oct 2026) and may ask the
people pictured. If anyone asks to be removed, delete the file **and** purge it
from history.

Added Oct 17 (Musco, with the instructor's camera map: **1, 3, 4, 6** close-ups —
two per operator — **2** static wide, **5** conductor cam, **7** backstage,
**8** PowerPoint/video, labeled "PP"):

- `musco/multiview-concert-pixelated.jpg` — the ATEM multiview during a wind
  symphony concert: Program and Preview on top, boxes 1–4 and 5–8 below, a
  close-up on Program, box 3 on Preview. **Pixelated on purpose**: the
  original shows students' faces in close-up, which this public repo doesn't
  need — the layout is the point. In the original, box 2 is a full-hall wide
  from the back, 6 shows the conductor from the side, 7 is mostly black.
- `musco/booth-multiviews-setup.jpg` — the booth during a band's setup: two
  multiview monitors and a small four-up monitor. Sticky note on the plush
  blurred.
- `musco/multiview-jubilee-preshow.jpg` — the multiview before a theater
  show, with a title graphic on box 8 ("PP").
